# 0010. 인증 시행은 기본 꺼짐으로 두고, 켜면 기동 때 전제를 검사한다

## 맥락
도메인 API 를 처음부터 인증 필수로 두면, 로그인 흐름이 끝나기 전의 앱 화면과 기존 클라이언트가 깨진다(설정 설명의 '현행 동작 보존·클라이언트 호환'). 공개본은 로컬에서 외부 키 없이 바로 돌아가야 한다.

## 선택지
1. 처음부터 인증 필수
2. 기본 꺼짐 + 스위치로 켜면 키·CORS·토큰을 기동 때 검사

## 결정
2번. `USER_AUTH_ENFORCED=false` 가 기본이다. 계정·신고·동의 경로는 이 값과 무관하게 늘 인증한다. 켜면 JWT 키·내부 서비스 토큰이 없거나 CORS 가 `*` 이면 기동을 멈춘다.

## 결과
로컬 빠른 시작이 쉽다. 대신 외부에 열기 전에 반드시 켜야 한다는 것을 README·SECURITY·`.env.example` 에 굵게 적었다.
