# 0005. Redis 논리 DB 를 용도별로 나눈다

## 맥락
JWT 폐기 목록, 요청 한도, 스트림, 초안, 채팅 접속 상태, 재사용 캐시가 모두 Redis 를 쓴다. 한 DB 에 섞이면 키 충돌을 피하기 어렵고, 한 용도만 비우거나 들여다보기도 어렵다.

## 선택지
1. 한 DB 에 접두어로 구분
2. 용도별 논리 DB 와 용도별 연결

## 결정
2번. 기본 0, JWT 폐기 1, 스트림 2, 카운터·요청 한도 3, 초안 4, 채팅 5, 재사용 캐시 6. 스트림 연결은 명령 시한을 따로 둔다.

## 결과
용도별로 비우고 관찰할 수 있다. 대신 다른 서비스와 공유하는 DB 번호(스트림 2 등)는 통합 실행 설정과 맞춰야 한다([troubleshooting.md](../troubleshooting.md) T-REDIS-01).
