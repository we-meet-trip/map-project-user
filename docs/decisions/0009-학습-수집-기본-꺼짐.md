# 0009. 학습 수집은 기본으로 끄고, 내보내기는 서빙과 다른 진입점으로 한다

## 맥락
추천 품질을 높이려면 후보·선택·편집·도착 기록이 필요하지만, 이것은 사용자의 이동과 선호를 담은 기록이다.

## 선택지
1. 항상 수집
2. 기본 꺼짐 + 명시적으로 켰을 때만 수집, 내보내기는 별도 실행
3. 수집 기능을 두지 않는다

## 결정
2번. `MAP_PROJECT_TRAINING_CAPTURE_ENABLED=false` 가 기본이다. 내보내기는 `map.export.TrainingExportApplication` 을 서빙과 따로 한 번 띄우고, 두 스위치(활성·승인)가 모두 켜져야 돈다. 사용자 식별자는 소금 섞은 지문으로 바꾼다.

## 결과
기본 설치는 학습 기록을 만들지 않는다. 켜려는 운영자는 처리방침에 목적·보관 기간을 적어야 한다([data.md](../data.md)).
