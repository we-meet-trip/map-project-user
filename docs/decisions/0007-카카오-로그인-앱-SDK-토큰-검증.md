# 0007. 카카오 로그인은 앱 SDK 가 받은 액세스 토큰을 서버가 검증한다

## 맥락
처음에는 서버가 인가 주소를 만들고 콜백에서 코드를 교환했다. 카카오 콘솔은 커스텀 스킴 리다이렉트를 받지 않아 서버가 앱으로 되돌려 보내는 중간 단계가 필요했고, 앱·서버·콘솔 설정이 바이트 단위로 맞아야 했다.

## 선택지
1. 서버 인가 코드 흐름 + 앱 복귀용 중간 리다이렉트
2. 앱이 카카오 SDK 로 로그인하고 서버는 액세스 토큰만 검증

## 결정
2번. 앱은 `POST /api/v1/auth/kakao/callback` 에 액세스 토큰을 보내고, 서버는 토큰 정보 API 로 그 토큰이 설정한 앱 번호(`USER_KAKAO_APP_ID`)에서 나왔는지 확인한 뒤 사용자 정보를 받는다. 토큰은 저장하지 않는다.

## 결과
서버가 인가 주소·리다이렉트·상태값을 관리하지 않는다. 앱 번호를 주지 않으면 카카오 로그인은 꺼진다. 토큰 정보·사용자 정보 API 주소는 카카오 것으로 고정하고 바꾸면 기동을 거부한다.
