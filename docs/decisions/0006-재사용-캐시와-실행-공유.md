# 0006. 같은 조건의 추천은 결과를 재사용하고, 돌고 있는 실행에 붙는다

## 맥락
추천 한 건이 언어 모델을 여러 번 부른다. 같은 지역·조건 요청이 자주 겹치고, 동시에 오면 모두 새로 만들었다.

## 선택지
1. 매번 새로 만든다
2. 완료 결과만 캐시
3. 완료 결과 캐시 + 만드는 중인 실행 공유(실행 세대 토큰)

## 결정
3번. 조건(지역·기간·테마·이동수단·예산·시간대)을 근사 해시로 묶어 7일 캐시하고, 같은 조건이 돌고 있으면 `SET NX` 로 정한 실행에 붙는다. 붙는 쪽도 자기 `job_id` 를 받고 결과는 사본으로 받는다. 날씨 재추천과 실패 결과는 캐시에 넣지 않는다.

## 결과
모델 호출이 줄었다. 대신 실행 세대·대기 기한·취소를 정확히 다뤄야 해 코드가 복잡하다(`RecommendFollowerIsolationTest`).
